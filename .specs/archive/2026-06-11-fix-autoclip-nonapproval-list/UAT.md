## UAT-1：已批准状态筛选 tab 可见

**前置**：数据库中存在至少一条 `status = 'approved'` 的 auto_clip_results 记录（非审批模式自动切片后产生）

1. 启动应用：`pnpm run dev`
2. 左侧菜单点击"自动切片"
3. 观察状态筛选 radio-group

**✅ 通过条件**：

- 筛选栏包含 7 个按钮：全部 / 待审核 / 已批准 / 导出中 / 已完成 / 已上传 / 失败
- "已批准" tab 显示正确的数量（counts.approved）

## UAT-2：keep-alive 数据自动刷新

**前置**：已在"自动切片"页面，可看到列表数据

1. 点击左侧菜单切换到"压制"页面
2. 等待 3 秒
3. 点击左侧菜单切回"自动切片"页面

**✅ 通过条件**：

- 列表数据自动刷新（无需手动点击"刷新"按钮）
- 数据与当前数据库状态一致

## UAT-3：已批准状态显示"重新导出"按钮并正常工作

**前置**：列表中存在一条 `status = 'approved'` 的记录（通过"已批准" tab 筛选）

1. 点击"已批准"筛选 tab
2. 找到一条记录，观察操作栏
3. 点击"重新导出"按钮

**✅ 通过条件**：

- 操作栏显示"重新导出"按钮（而非"确认导出"）
- 点击后弹出通知"正在导出 N 个切片..."
- 导出完成后状态变为"已完成"（exported）
- 导出文件存在于预期目录

---

## UAT-4：待审核状态行为不变

**前置**：列表中存在一条 `status = 'pending'` 的记录

1. 点击"待审核"筛选 tab
2. 确认操作栏显示"确认导出"按钮
3. 点击"确认导出"

**✅ 通过条件**：

- pending 状态行为无回归，按钮文字为"确认导出"
- 导出正常完成
