## 人工 UAT（需在 GUI 环境执行）

> 启动 Electron 应用后逐条验证。

### UAT-1：编码器下拉选择

1. 打开 设置 → 自动切片 → 编辑预设
2. 选择一个预设，切换到「导出设置」Tab
3. 点击「视频编码器」字段
4. **预期**：显示下拉框，列出 libx264 / h264_nvenc / hevc_nvenc / av1_nvenc / h264_qsv 等编码器
5. 选择 `h264_nvenc`，保存预设，关闭对话框
6. 重新打开同一预设 → 确认编码器仍为 `h264_nvenc`

- [ ] 通过 / 失败 / 描述：

### UAT-2：FFmpeg 预设下拉选择

1. 在「导出设置」Tab 中，点击「FFmpeg 预设」字段
2. **预期**：显示下拉框，列出已配置的 FFmpeg 预设（如 default / H.264(NVIDIA NVEnc) 等）
3. 选择一个预设，保存
4. 重新打开确认预设选择持久化

- [ ] 通过 / 失败 / 描述：

### UAT-3：两个字段独立

1. 选择一个 FFmpeg 预设（如 H.264(NVIDIA NVEnc)）— 编码器字段不变
2. 单独修改编码器字段为 `libx265` — FFmpeg 预设字段不变
3. 保存后确认两个字段值都正确持久化
