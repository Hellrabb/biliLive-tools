### 1.2 UAT 脚本

#### UAT-1 · 自定义预设出现在下拉中

```
前置：已在"压制页面 → FFmpeg设置"中创建了至少一个自定义预设（例如 "My AV1"）
步骤：
  1. 打开 AutoClip 管理页面
  2. 点击新建/编辑预设，打开 AutoClipPresetDialog
  3. 切换到"导出设置"tab
  4. 点击"FFmpeg 预设"下拉
期望：
  - 下拉显示两个分组："基础"和"自定义"
  - "自定义"分组中包含 "My AV1"
  - 选中 "My AV1" 后，下拉值更新为该预设
通过/失败：
```

#### UAT-2 · 下拉展示内置 + 自定义预设（分组）

```
前置：AutoClipPresetDialog 已打开，"导出设置"tab 激活
步骤：
  1. 点击"FFmpeg 预设"下拉
期望：
  - "基础"分组包含全部内置预设（H.264 NVEnc / H.265 NVEnc / AV1 NVEnc / ...）
  - 每个预设显示名称，不显示内部 ID（b_nvenc_h264 → "H.264(NVIDIA NVEnc)"）
  - "自定义"分组包含用户创建的所有预设；如无自定义预设，该分组为空
通过/失败：
```

#### UAT-3 · 选中预设后显示参数预览

```
前置：FFmpeg 预设下拉已可用
步骤：
  1. 从"FFmpeg 预设"下拉选择一个内置预设 "H.265(NVIDIA NVEnc)"
期望：
  - 下拉下方出现 <n-descriptions> 预览卡片，显示：
    编码器: hevc_nvenc
    码率控制: VBR
    码率: 8000 kbps
    Preset: p3 (fast)
    CRF: 28
    10-bit: 否
  - 卡片底部显示"内置预设 · 在预设管理中复制后编辑"（内置预设）或"编辑此预设 →"（自定义预设）
  2. 点击 clearable 清空预设选择
期望：
  - 预览卡片消失
通过/失败：
```

#### UAT-4 · 选中预设后自动同步 encoder 字段

```
前置：AutoClip 导出设置 tab，encoder 当前值为 "libx264"
步骤：
  1. 从"FFmpeg 预设"下拉选择 "H.265(NVIDIA NVEnc)"
期望：
  - encoder 字段自动变为 "hevc_nvenc"
  2. 手动将 encoder 改为 "libx265"
期望：
  - encoder 变为 "libx265"
  - FFmpeg 预设选择仍为 "H.265(NVIDIA NVEnc)"（不丢失）
  3. 点击 clearable 清空预设选择
期望：
  - 预览卡片消失
  - encoder 保持 "libx265"（不清空）
通过/失败：
```

#### UAT-5 · 跳转链接可操作

```
前置：已选中一个自定义预设（非 b_ 开头 ID），预览卡片可见
步骤：
  1. 点击"编辑此预设 →"链接
期望：
  - 浏览器导航到 /#/home?tab=ffmpeg-setting
  - Home 页面自动切换到"ffmpeg设置"tab
  2. 回到 AutoClip 对话框，选中一个内置预设（如 "H.265(NVIDIA NVEnc)"）
期望：
  - 预览卡片底部显示"内置预设 · 在预设管理中复制后编辑"（不可点击）
通过/失败：
```

#### UAT-6 · 加载失败时不再静默吞错

```
前置：可以通过停止后端 HTTP 服务 或 临时改 API 路径来模拟失败
步骤：
  1. 关闭后端 HTTP 服务（或模拟 /preset/ffmpeg/options 返回 500）
  2. 打开 AutoClip 预设对话框
期望：
  - 出现错误通知："FFmpeg 预设加载失败，请检查服务状态"（使用已有 notice.error()）
  - "FFmpeg 预设"下拉为空
  - 其他导出设置（encoder / 音频编码器 / 弹幕压制等）仍可正常编辑
通过/失败：
```
