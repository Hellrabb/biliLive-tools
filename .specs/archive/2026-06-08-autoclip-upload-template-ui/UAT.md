## 人工 UAT

### UAT-1：B站模板表单显隐

- **前置**：启动 Electron 应用 (`pnpm run dev`)，打开设置 → 切片设置 → autoclip 预设编辑
- **步骤**：
  1. 切换到「导出设置」tab
  2. 确认「上传到B站」开关为关闭 → 下方无 B站模板字段
  3. 打开「上传到B站」开关
  4. 观察 8 个字段出现：标题模板 / 标签 / 投稿分区 / 自制转载 / 禁止转载 / 简介模板 / 封面图
  5. 切换到「转载」→ 转载来源字段出现，禁止转载隐藏
  6. 切回「自制」→ 禁止转载出现，转载来源隐藏

- **期望**：字段显隐与 copyright 值联动正确，变量提示文字可见
- **通过 / 失败**：🟡 待用户手动测试

### UAT-2：分区列表加载

- **前置**：已通过浏览器访问过 B站设置页面（`areaData` 已缓存至 localStorage）
- **步骤**：
  1. 打开 autoclip 预设编辑弹窗 → 导出设置 tab
  2. 打开上传到B站
  3. 点击投稿分区下拉
- **期望**：级联列表正常展开，可逐级选择分区，默认显示 138（生活·日常）
- **通过 / 失败**：🟡 待用户手动测试

### UAT-3：保存与回显

- **步骤**：
  1. 配置标题模板为 `{{highlightTitle}} - 测试`
  2. 添加标签 `测试标签`
  3. 选择分区 138
  4. 点击保存
  5. 关闭弹窗后重新打开该预设
- **期望**：所有字段值回显正确
- **通过 / 失败**：🟡 待用户手动测试
